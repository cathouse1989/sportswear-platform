# 验收用例 · 操作日志（/operation-logs）

> 前置角色：super_admin / admin（setting:manage）；关联：说明书 §5.4

| # | 类型 | 步骤 | 预期 |
|---|------|------|------|
| 1 | 正向 | 执行一次后台写操作后打开日志 | 对应 create/update/delete 记录出现，操作列显示中文标签（发布/下线/上传/登录等 8 类映射） |
| 2 | 正向 | 按模块名 + 操作类型组合筛选 | 结果精确匹配 |
| 3 | 正向 | 检查时间列 | 本地化格式展示，空值显示"-" |
| 4 | 标记 | 查看修改前后 diff | 无此能力（依赖平台中优 #8 日志完善，P1-#10 前端配合） |
