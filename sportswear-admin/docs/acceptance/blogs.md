# 验收用例 · 博客管理（/blogs）

> 前置角色：content_admin；关联：说明书 §4.2、§8 B-01（回归）

| # | 类型 | 步骤 | 预期 | 回归 |
|---|------|------|------|------|
| 1 | 正向 | 点击"新建博客" | 弹出编辑弹窗 | B-01 |
| 2 | 反向 | 标题/Slug/分类/正文留空直接保存 | 行内红字提示，不发出请求 | B-01 |
| 3 | 反向 | Slug 输入 `Abc 1` | 提示"仅允许小写字母、数字和中划线" | |
| 4 | 正向 | 合法填写（含标签/封面 URL）保存 | toast"保存成功"，列表刷新出现新行 | |
| 5 | 正向 | 草稿行点"发布" | 状态变 published；门户 `/en/blog/:slug` 可访问 | |
| 6 | 正向 | 行数据含 cover_image | 列表显示缩略图，点击可预览 | |
| 7 | 正向 | 编辑已有博客修改正文保存 | 弹窗回填原值，保存后列表更新 | |
| 8 | 正向 | 删除博客并确认 | 移入回收站（类型=blog），前台不可见 | |
| 9 | 反向 | 清空正文后对草稿点"发布" | 被拦截，弹出"无法发布"并列出缺失项（P0-#2 质检门） | |
| 10 | 反向 | 仅缺封面图时发布 | 不阻断（警告提示"建议补充封面图"），可正常发布 | |

> 遗留标记：无 unpublish 动作（B-10 待办），用例暂不含下线路径。
