# 验收用例 · 工厂管理（/factories）

> 前置角色：content_admin / admin（factory:manage）；关联：说明书 §4.2

| # | 类型 | 步骤 | 预期 |
|---|------|------|------|
| 1 | 正向 | 新建工厂（名称/位置/员工数/描述） | 列表出现草稿行 |
| 2 | 正向 | 发布 → 状态 published；门户 /en 工厂区块可见；下线可逆 | 双动作生效 |
| 3 | 正向 | 客户端搜索工厂名 | 前端过滤生效（本地 computed 分页） |
| 4 | 反向 | 删除工厂并确认 | 进回收站（类型=factory，B-02 修复后可在回收站按该类型检索恢复） |
