# 验收用例 · 页面管理（/pages）

> 前置角色：content_admin（发布需 page:publish）；关联：说明书 §4.2、§8 B-13（回归）

| # | 类型 | 步骤 | 预期 | 回归 |
|---|------|------|------|------|
| 1 | 正向 | 新建页面（标题/Slug/类型/排序） | 弹窗表单可提交，列表出现草稿行 | |
| 2 | 正向 | 草稿行点"发布"→ 状态变 published → 点"下线" | 双动作流转正常，门户对应 slug 同步可见/不可见 | |
| 3 | 正向 | 混合状态列表筛选"草稿" | **所有行状态 tag 颜色按行数据正确显示**（修复前全列随筛选值变色） | B-13 |
| 4 | 正向 | 删除已发布页面并确认 | 移入回收站（类型=page） | |
| 5 | 正向 | 编辑弹窗「模块编辑」Tab：添加/上下移动/隐藏/删除模块，Config 填非法 JSON 时保存被拦截 | 模块列表完整回填，保存后后端 page_modules 同步重建 | |
| 6 | 正向 | 编辑弹窗「多语言翻译」Tab：添加 en/zh 翻译并保存 | 列表「翻译」列显示语言标签，后端 page_translations upsert | |
| 7 | 正向 | 编辑弹窗「版本历史」Tab：存草稿版本 → 发布版本 → 回滚 | 版本号递增、发布后归档旧版、回滚复制快照并发布 | |
| 8 | 正向 | 已发布页面仅改标题保存 → 再次打开 | 状态仍为 published（回归：UpdatePage 不再清空空 status） | |
| 9 | 标记 | 模块结构化表单编辑 | 当前为 Config JSON 编辑器，按模块类型的结构化表单待后续迭代 | |
