# 验收用例 · FAQ 管理（/faqs）

> 前置角色：content_admin；关联：说明书 §4.2、§8 B-01（回归）

| # | 类型 | 步骤 | 预期 | 回归 |
|---|------|------|------|------|
| 1 | 正向 | 点击"新建 FAQ" | 弹出编辑弹窗（问题/答案/分类/语言/排序） | B-01 |
| 2 | 反向 | 问题或答案留空保存 | 行内红字提示 | |
| 3 | 正向 | 编辑已有 FAQ | 语言与排序正确回填（修复前 sort_order 恒回 0） | B-01 |
| 4 | 正向 | 选择语言 es 保存 | 列表语言列显示 es，门户西语站可读到 | |
| 5 | 正向 | 按分类筛选（如 MOQ） | 列表仅剩该分类，标签显示中文（统一常量） | |
| 6 | 正向 | 删除 FAQ 并确认 | 移入回收站（类型=faq） | |
