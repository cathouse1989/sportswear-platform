# 验收用例 · 媒体管理（/media）

> 前置角色：content_admin / product_admin；关联：说明书 §4.5、§8 B-08

| # | 类型 | 步骤 | 预期 |
|---|------|------|------|
| 1 | 正向 | 新建媒体记录（手动填 URL 等元数据） | 列表出现记录，编辑回显正确 |
| 2 | 正向 | 复制链接按钮 | 剪贴板获得 URL，toast"已复制" |
| 3 | 正向 | 删除媒体记录 | 进回收站（类型=media，B-02 修复后可选） |
| 4 | ⚠️ 现状 | 尝试上传真实文件 | **当前无上传能力**（B-08：MinIO 直传未接通，待 P0-#4）；该用例在闭环落地后转为正向用例：拖拽上传→进度→媒体库选择器回填产品封面 |
