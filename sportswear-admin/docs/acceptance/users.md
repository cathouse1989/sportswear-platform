# 验收用例 · 用户管理（/users）

> 前置角色：super_admin（user:*）；关联：说明书 §3、§8 B-15（回归）

| # | 类型 | 步骤 | 预期 | 回归 |
|---|------|------|------|------|
| 1 | 正向 | 新建用户（邮箱/姓名/角色） | 列表出现新用户，状态 active | |
| 2 | 正向 | 编辑用户行 | 表单正确回填（插槽类型修复后无控制台报错） | B-15 |
| 3 | 正向 | 禁用用户（status=disabled） | 该用户再登录被拒；已有 Token 行为按权限矩阵 §五（仍有效至过期，建议配合审计） | |
| 4 | 正向 | 删除用户并确认 | 二次确认后移入回收站（类型=user） | |
| 5 | 标记 | 重置密码能力 | ⚠️ 页面暂未发现重置密码入口（B-10 待办），落地后补用例 | |

> 遗留标记：应用维度授权（app_users）界面属于 P1-#10 应用管理页范围。
