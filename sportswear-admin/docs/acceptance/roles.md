# 验收用例 · 角色权限（/roles）

> 前置角色：super_admin（role:manage）；关联：说明书 §3、platform/docs/权限矩阵.md、§8 B-15（回归）

| # | 类型 | 步骤 | 预期 | 回归 |
|---|------|------|------|------|
| 1 | 正向 | 新建角色并勾选权限集合 | 保存后角色列表出现；权限立即生效（每次请求实时加载） | |
| 2 | 正向 | 用开关禁用某角色 | 该角色用户**立即**失去对应权限（403），无需重新登录 | |
| 3 | 正向 | 切换开关（el-switch） | 事件正常触发不报类型错误 | B-15 |
| 4 | 正向 | 点"权限"打开权限配置弹窗 | 权限树/列表与权限矩阵九角色语义一致 | |
| 5 | 反向 | 禁用 super_admin 自身角色 | 系统应阻止或显著警告（若现状允许禁用，记录为待办） | |
