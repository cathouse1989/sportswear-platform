# 验收用例 · 仪表盘（/dashboard）

> 前置角色：super_admin / admin / sales_manager（dashboard:view）；关联：说明书 §4

| # | 类型 | 步骤 | 预期 |
|---|------|------|------|
| 1 | 正向 | 进入仪表盘 | 四张统计卡展示：今日/本周/本月/高价值询盘（数据源 `/admin/dashboard`） |
| 2 | 正向 | 存在多国询盘数据 | "热门产品 Top5"/"热门国家 Top5" 榜单按数量降序展示，行尾带"N 条询盘" |
| 3 | 正向 | 无任何询盘数据 | 两张榜单显示 el-empty 空态，无报错 |
| 4 | 反向 | 后端统计接口失败 | 页面静默降级（卡片显示 0），不白屏 |
