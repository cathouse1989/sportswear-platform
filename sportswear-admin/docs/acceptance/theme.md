# 验收用例 · 主题配置（/theme）

> 前置角色：super_admin / admin（setting:manage）；关联：说明书 §4.5、§6 联动机制

| # | 类型 | 步骤 | 预期 |
|---|------|------|------|
| 1 | 正向 | 修改 Logo URL / 品牌名称 / 副标题 / alt / favicon 后点"保存 Logo 配置" | 五个键并发保存，toast"Logo 配置已保存"；左侧栏 Logo 即时更新 |
| 2 | 正向 | 用"上传"按钮上传本地图片 | 走 `/api/v1/admin/media/upload`（带 Bearer），成功后 URL 回填（⚠️ 该上传通道是否可用取决于后端 B-08 进度，失败应 toast"上传失败"） |
| 3 | 正向 | 修改 primary_color 等颜色项（输入框 + 取色器联动） | 行级"保存"生效 |
| 4 | 正向 | 保存后在"门户预览"页与门户前台核对 | 主题/Logo 实时生效，无需重新部署 |
| 5 | 反向 | 上传非图片扩展名 | 被 accept 限制或后端拒绝并提示 |
