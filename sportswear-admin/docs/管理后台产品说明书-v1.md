## 一、产品定位与用户角色

### 1.1 定位一句话

面向运动服饰 OEM/ODM 出海业务的运营人员，提供 **「产品(PIM) + 内容(CMS) + 商机(Leads)」** 一体化的中文管理后台；所有内容经此编辑并受发布状态控制，最终呈现于 sportswear-portal 门户（en/zh/es/fr 四语）。

### 1.2 技术形态

| 项 | 现状 |
|----|------|
| 框架 | Vue 3.5 + TypeScript 5.6 + Vite 6 |
| UI | Element Plus 2.9 + @element-plus/icons-vue |
| 状态/路由 | Pinia 2.3 / vue-router 4.5 |
| 国际化 | vue-i18n 11（界面文案 zh/en 两包，见 `src/locales/`） |
| HTTP | axios（统一封装于 `src/api/client.ts`，响应结构 `{success, code, message, data, requestId}`） |
| 图表 | echarts 5 |
| 工程护栏 | ✅ v1.2 起：`npm run lint / test / typecheck / format` 脚本齐备（ESLint 9 扁平配置 + Prettier + Vitest 冒烟 6 例）；CI 流水线与 lint 告警清零仍待推进（P0-#6） |

### 1.3 用户角色（引用 platform/docs/权限矩阵.md）

| 角色 | 主要职责 | 典型可见页面 |
|------|---------|-------------|
| super_admin | 平台所有权限、用户/角色/应用管理 | 全部 |
| admin | 日常全量运营 | 除应用管理等少数项外全部 |
| content_admin | 内容运营（页面/博客/案例/FAQ/媒体） | 内容管理 + 媒体 |
| product_admin | 产品资料维护 | 产品 + 分类/系列/面料 + 媒体 |
| seo_admin | SEO 与部分内容查看 | 页面/博客查看 + SEO |
| sales_manager | 询盘处置、报表 | 询盘 + 仪表盘 + 分析 |
| sales | 询盘跟进 | 询盘 |
| editor | 内容录入（不可发布） | 页面编辑 + 博客等 manage |
| viewer | 只读浏览 | 各列表页 |

权限码体系：`<资源>:view/create/update/delete/publish/manage`；路由级由 `src/router/index.ts` 的 `meta.permission` 守卫（**any-of 语义**：命中数组任一即放行），按钮级控制现状薄弱（见缺陷 B-07）。

## 三、登录、会话与权限行为（现状）

| 行为 | 说明 |
|------|------|
| 登录 | `POST /api/v1/admin/auth/login`，邮箱+密码；默认管理员 `admin@sportswear.com / Admin@123456`（仅限本地） |
| 会话 | JWT，24h 过期；Pinia `stores/auth.ts` 持久化 token；刷新页面自动 `fetchProfile()` 恢复用户与权限 |
| 守卫 | 全局前置守卫：无 token → `/login`；带 `meta.permission` 页面做 any-of 校验，未授权**静默跳转**到 `/dashboard`（建议改为提示页，见打磨方案 P1-#11）；any-of 判定已收敛至 `utils/permissions.hasAnyPermission`，按钮级 `v-permission` 指令已注册（示范：pages 发布/下线、users 删除） |
| 退出 | 右上角下拉确认后 `logout()` 并回登录页 |
| 未读通知 | Header 铃铛拉取 `unreadCount` 角标（点击暂无跳转联动） |
| 品牌 | Logo 从主题配置 `logo_url/logo_alt` 读取，支持后台换标 |

## 五、数据规范与状态机

### 5.1 发布状态机（产品/面料等带 Status 的对象）

```
draft ──publish──▶ published ──offline──▶ offline
  ▲                    │                     │
  └─────── 重新编辑可回 draft ◀── publish ───┘
Public API 仅暴露 published；admin 一律可见全量。
```

辅以两层布尔开关语义：`is_active`（业务可用性，如角色禁用立即生效）、`is_public/is_visible`（前台显隐）。

### 5.2 多语言模型

主表存 en 源内容（如 products.brief），translations 按 language 冗余独立 status；后台界面文案走 vue-i18n 静态包 + i18n_entries 动态词条双轨。

### 5.3 SEO 字段全集

`entity_type(product|page|blog|case|category) × entity_id × language` → title(200)/description/keywords(500)/canonical/robots/og_title/og_description/og_image/schema_data。SEO 管理入口目前散落在各实体编辑区内，无集中视图。

### 5.4 全局技术约定

UUID 主键全局唯一；JSONB 存模块配置与版本快照；所有响应携带 requestId 贯穿 app/access/audit 三类日志；软删除配合回收站；公开接口只读 + IP 限频 30/min。

## 六、后台 × 门户联动机制

| 改动位置（admin） | 生效链路 | 前台表现 |
|------------------|---------|---------|
| 产品/页面/博客… 发布 | 写库 status=published → Public API 即读即见（当前无缓存层） | 立即可见；下线/回收站同理即时消失 |
| 主题配置 /theme | `PUT /admin/theme/:key` → theme_configs → portal `GET /public/theme` | 颜色/字体/Logo 全站实时切换，无需重新部署 |
| 词条管理 /i18n | i18n_entries → portal 动态词条接口 | 门户 UI 文案热更新 |
| 存储源配置 | storage_sources 默认源切换 | 影响后续媒体写入位置 |
| 询盘提交 | portal 表单 POST /public/leads（限频）→ admin 通知 + 列表 | 销售侧实时可见、可跟进 |

> 页面级"版本快照/回滚"能力在需求文档 §5.5 已定义，admin 当前实现到模块配置层级，版本化 UI 属 P1 后 backlog。

## 七、内容质检基线与验收用例

### 7.1 质检基线（发布卡点依据）

> 标注说明：**[现状]** = 今天代码已具备的默认值/约束；**[新增约束]** = 由 `src/utils/publish-gate.ts` 质检门强制执行（产品/博客已接入，others P1），缺失阻断项在发布时弹出"无法发布"清单。

| 类别 | 条目 | 性质 |
|------|------|------|
| 基础字段 | SKU/slug 全局唯一；name/brief/description 必填（产品发布阻断）；类型限定 oem·odm·both 三值；性别枚举合法 | [现状]+[新增约束✅] |
| 视觉素材 | 封面必传（产品发布阻断；博客仅警告不阻断）[新增约束✅]；≥3 张图集且均含 alt（P1 待强检）[新增约束]；单图 ≤2MB、JPG/WebP/PNG ≥800px 宽 | [新增约束] |
| 商务 | MOQ 为正整数且 sample≤production（发布阻断）[新增约束✅，基础默认1/300/100/100]；season/size_range 合法枚举或自由文本 | 混合 |
| 多语言 | 至少 en 一门语言完整（其余语言允许 untranslated）[新增约束：发布时列出未翻译语言数提示但不阻断] | 新增 |
| SEO | title≤60 字符、description≤160 字符、og_image 与封面一致 [新增约束：缺失时警告不阻断，title/desc 缺失阻断] | 新增 |
| 内容合规 | description 不含站外死链/占位符（lorem 等）[新增约束] | 新增 |

### 7.2 验收用例生成与维护规则

- 用例文件路径约定 `docs/acceptance/<route>.md`（如 `acceptance/products.md`），每个菜单页一份；
- 结构固定：前置条件（角色+数据）→ 步骤 → 预期 → 关联缺陷号；
- 来源映射：第四章表格「已具备的能力」逐条转正/反向用例（发布成功、缺封面发布被拦、禁用角色按钮隐藏等）；
- 示例两则：
  - **blogs**：以 sales_manager 登录 → 点击"新建博客" → 应弹出编辑表单（B-01 修复后回归项）；
  - **products**：以 viewer 登录 → 进入产品列表 → 所有写操作按钮不可见或禁用。
