# 国际化运动服饰 OEM/ODM 平台 - 技术方案

## 一、项目概述

基于 PRD 文档，建设一个国际化 B2B 运动服饰 OEM/ODM 数字化平台，包含：

- **商家管理后台**（Admin CMS）：内容、产品、媒体、多语言、SEO、询盘、CRM 管理
- **客户前台 API**（Public API）：面向全球访客的公开只读接口
- **落地页公开信息**：SEO 落地页、产品页、博客、案例等

## 二、技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 后端语言 | Go 1.22+ | 高性能、并发安全 |
| Web 框架 | Gin | 轻量、中间件丰富 |
| ORM | GORM | 支持 PostgreSQL、自动迁移 |
| 数据库 | PostgreSQL 15+ | 主数据库，UUID 主键，JSONB 配置 |
| 缓存 | Redis 7+ | 页面缓存、会话、频率限制 |
| 对象存储 | MinIO（本地）/ S3（生产） | 图片、视频、文件存储 |
| 认证 | JWT + RBAC | 登录认证 + 角色权限 |
| API 文档 | Swagger | 自动生成 OpenAPI 文档 |
| 配置 | Viper + .env | 环境配置管理 |
| 日志 | Zap | 结构化日志 |
| 校验 | Validator | 参数校验 |

## 八、核心设计原则

1. **内容与代码分离**：所有内容后台可管理，代码只负责功能
2. **图片与页面分离**：媒体资源统一管理，只维护一份
3. **多语言与业务数据分离**：翻译表独立，支持语言回退
4. **页面模块化**：页面由模块组成，后台可配置
5. **API First**：所有功能通过 API 暴露，支持多端
6. **后台可运营**：运营人员无需改代码即可完成 80% 日常运营
