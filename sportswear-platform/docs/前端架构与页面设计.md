# 前端架构与页面设计文档

## 一、架构决策总览

### 1.1 核心结论：两个应用分离（而非合并）

| 维度 | 后台管理（Admin） | 门户落地页（Public） |
|------|------------------|---------------------|
| 用户 | 运营/销售/管理员 | 全球 B2B 访客 |
| 技术形态 | **SPA**（单页应用） | **SSR**（服务端渲染） |
| SEO | 不需要 | **核心获客手段** |
| 框架 | **Vue 3 + Vite + Element Plus** | **Nuxt 3**（Vue 3 SSR 框架） |
| 首屏 | 秒开（本地加载） | SEO 爬虫可抓取 |
| 部署 | 内网/白名单 | CDN 全球加速 |

**分离理由**：
1. 技术形态不同（SPA vs SSR），合并会互相拖累
2. 优化目标冲突（后台秒开 vs 门户 SEO）
3. 部署独立（后台可加白名单，门户走 CDN）
4. 权限隔离更安全

### 1.2 技术栈选型

```
┌─────────────────────────────────────────────────────────┐
│                    pnpm workspace（monorepo）             │
├─────────────────────────────────────────────────────────┤
│  apps/admin          apps/portal         packages/shared  │
│  Vue3 + Vite         Nuxt 3              TS 类型 + API 封装 │
│  + Element Plus      + Tailwind CSS       + 工具函数        │
│  + Pinia + Vue Router + i18n              + 常量            │
│  + ECharts           + Pinia + SEO        └───────────────┘
└─────────────────────────────────────────────────────────┘
                          ↓ HTTP/JSON
                 ┌────────────────────┐
                 │  Go 后端 API (Gin)  │
                 │  /api/v1/public/*  │
                 │  /api/v1/admin/*   │
                 └────────────────────┘
```

**为什么用 Vue**：完全可行，且是当前最推荐方案。
- Element Plus 是中文生态最成熟的后台 UI 库，表格/表单/权限组件齐全
- Nuxt 3 是 Vue 官方 SSR 框架，SEO、多语言、hreflang 原生支持
- 两个应用共享 Vue 技术栈，团队学习成本低

**备选**：若团队熟悉 React，可换 Next.js + Ant Design，架构决策不变。

### 3.3 权限控制

基于后端 RBAC 权限码，前端做路由级 + 按钮级权限控制：

```
路由守卫 → 检查 JWT token → 拉取用户权限 → 匹配路由 meta.permission
按钮级 → v-permission="'product:delete'" 指令
```

后端权限码（已实现）：
`user:view/create/update/delete`、`role:manage`、`product:view/create/update/delete/publish`、`category:manage`、`series:manage`、`fabric:manage`、`page:view/update/publish`、`navigation:manage`、`blog:manage`、`case:manage`、`faq:manage`、`factory:manage`、`certification:manage`、`production:manage`、`media:manage/upload`、`lead:view/update/followup`、`dashboard:view`、`setting:manage`、`seo:manage`、`language:manage`

## 四、门户落地页（Public）页面设计

### 4.1 SSR + SEO 架构

```
爬虫/用户请求
    ↓
Nuxt 3 SSR（useFetch 服务端请求后端 API）
    ↓ 返回完整 HTML（含 SEO meta + 内容）
搜索引擎可抓取完整内容
```

**多语言 URL 结构**（子路径方案，SEO 最佳实践）：
```
https://site.com/en/          → 英文首页
https://site.com/zh/          → 中文首页
https://site.com/en/products/yoga-leggings  → 产品页
https://site.com/zh/products/yoga-leggings  → 中文产品页
```

**hreflang 标注**（Nuxt i18n 模块自动生成）：
```html
<link rel="alternate" hreflang="en" href="https://site.com/en/..." />
<link rel="alternate" hreflang="zh" href="https://site.com/zh/..." />
<link rel="alternate" hreflang="x-default" href="https://site.com/..." />
```

### 4.2 页面清单

| 页面 | 路由 | 后端 API |
|------|------|---------|
| 首页 | /:lang/ | GET /public/home?lang=xx |
| 产品列表 | /:lang/products | GET /public/products?lang=xx |
| 产品详情 | /:lang/products/:slug | GET /public/products/:slug?lang=xx |
| 分类页 | /:lang/categories/:slug | GET /public/categories |
| OEM 服务 | /:lang/oem | GET /public/pages/oem |
| ODM 服务 | /:lang/odm | GET /public/pages/odm |
| 工厂展示 | /:lang/factory | GET /public/factories |
| 案例列表 | /:lang/cases | GET /public/cases |
| 博客列表 | /:lang/blog | GET /public/blogs |
| 博客详情 | /:lang/blog/:slug | GET /public/blogs/:slug |
| FAQ | /:lang/faq | GET /public/faqs |
| 联系我们 | /:lang/contact | GET /public/pages/contact |
| 询盘表单 | - | POST /public/leads |
| Sitemap | /sitemap.xml | 后端生成 |

### 4.3 首页模块化渲染

首页由后端返回的 PageModules 驱动（后端已完成模块化）：

```
后端返回：
{
  "page": {
    "modules": [
      { "type": "hero", "config": {...} },        → Hero 横幅组件
      { "type": "product_recommend", ... },        → 产品推荐组件
      { "type": "factory", ... },                  → 工厂展示组件
      { "type": "certification", ... },            → 认证展示组件
      { "type": "process", ... },                  → 生产流程组件
      ...
    ]
  }
}

前端映射：
type → 组件渲染器
  hero → HeroBanner.vue
  product_recommend → ProductGrid.vue
  factory → FactorySection.vue
  certification → CertificationSection.vue
  ...
```

### 4.4 国际化集成

门户落地的国际化能力（后端全已支持）：
- **多语言**：`GET /public/i18n?lang=xx` 获取词条字典 + 内容接口按 lang 返回翻译
- **多货币**：`GET /public/currencies` 货币列表 + `GET /public/currencies/convert` 转换
- **地理定位**：`GET /public/geo` 自动推荐语言/货币/时区
- **时区**：`GET /api/v1/time` 服务器时间 + 时区列表
- **主题**：`GET /public/theme` 视觉风格配置
- **单位**：`GET /public/units/sizes` 尺寸对照 + 转换

前端切换语言/货币流程：
```
用户切换语言 → Nuxt i18n 切换 → 路由 /zh/... → useFetch 带 ?lang=zh → 内容自动切换
用户切换货币 → 后端 /public/currencies/convert?amount=&to= → 前端重新渲染价格
```

## 六、数据流与状态管理

```
后端 API
   ↓
共享包 ApiClient
   ↓
（Admin）Pinia store → 组件
（Portal）Nuxt useFetch/useAsyncData（SSR 友好）→ 组件
```

**Admin 状态**（Pinia）：
- `authStore`：token、用户信息、权限列表
- `productStore`：产品列表、当前编辑产品
- `notificationStore`：未读通知数（轮询）

**Portal 状态**（Nuxt）：
- 优先用 `useAsyncData`（服务端渲染 + 客户端水合）
- 轻量 UI 状态用 `useState`

## 七、部署架构

```
                    ┌──────────────────────┐
                    │   Cloudflare/CDN      │
                    │  （全球加速 + DDoS防护）│
                    └──────────┬───────────┘
                               ↓
        ┌──────────────────────┼──────────────────────┐
        ↓                      ↓                      ↓
  portal.example.com    admin.example.com     api.example.com
  （Nuxt SSR 门户）      （Vue SPA 后台）      （Go 后端 API）
        │                      │                     │
        │                      │ 内网/IP白名单        │
        └──────────┬───────────┴──────────┬──────────┘
                   ↓                      ↓
              PostgreSQL              Redis + MinIO
```

**关键部署要点**：
1. 后台 `admin.example.com` 可加 IP 白名单 / VPN 内网访问
2. 门户 `portal.example.com` 走 CDN + SSR
3. API 与前端同源或 CORS 配置
4. 静态资源（图片/视频）走 MinIO + CDN

## 十、总结

| 决策项 | 方案 |
|--------|------|
| 合并 vs 分离 | **分离**（Admin SPA + Portal SSR） |
| 技术栈 | **Vue 3 全家桶**（Element Plus / Nuxt 3） |
| 工程结构 | **pnpm monorepo**（2 app + 1 shared） |
| 后台 | Vue 3 + Vite + Element Plus + Pinia（SPA） |
| 门户 | Nuxt 3 + Tailwind（SSR，SEO 优先） |
| 多语言 | Nuxt i18n + 后端 i18n 词典 + hreflang |
| 权限 | 前端路由守卫 + 后端 RBAC 硬控 |

方案已完整覆盖后端已有 API，前后端可无缝对接。
