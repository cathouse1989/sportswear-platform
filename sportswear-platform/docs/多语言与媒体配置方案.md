# 多语言（i18n）与媒体源配置方案

## 一、多语言国际化方案（bbl / i18n）

### 1. 设计目标

面向全球网站，服务端统一配置多语言，前端切换语言时，接口返回内容自动切换对应语言（默认英文），前端通过词条字典接口解决界面文案翻译。

```
前端切换语言（?lang=zh 或 Accept-Language 头）
        ↓
语言解析中间件 → 解析目标语言
        ↓
内容接口：返回该语言的翻译内容（无则回退英文）
词条接口：返回该语言的 UI 文案字典
        ↓
前端一键切换界面语言
```

### 2. 语言解析机制（已实现）

优先级：`lang` 查询参数 → `X-Lang` 请求头 → `Accept-Language` 头 → 默认 `en`

```bash
# 指定语言
GET /api/v1/public/i18n?lang=zh
GET /api/v1/public/i18n?lang=en

# 通过请求头
GET /api/v1/public/i18n
X-Lang: zh

# 浏览器自动
GET /api/v1/public/i18n
Accept-Language: zh-CN,zh;q=0.9
```

### 3. 词条字典接口（公开）

```
GET /api/v1/public/i18n?lang=zh

返回：
{
  "language": "zh",
  "dictionary": {
    "nav.home": "首页",
    "nav.products": "产品",
    "btn.submit": "提交",
    "form.name": "姓名",
    ...
  }
}
```

前端拿到 dictionary 后，按 key 渲染界面文案，一键切换语言。

### 4. 词条管理 API（后台）

| 接口 | 权限 | 说明 |
|------|------|------|
| GET /admin/i18n/entries | language:manage | 词条列表（可按语言/模块/关键词筛选） |
| POST /admin/i18n/entries | language:manage | 创建/更新词条（key+language 唯一） |
| DELETE /admin/i18n/entries/:id | language:manage | 删除词条 |

### 5. 词条数据结构（i18n_entries 表）

```go
type I18nEntry struct {
    Key       string  // 词条键：nav.home、btn.contact、footer.copyright
    Language  string  // 语言：en/zh/es/fr/de
    Value     string  // 文案内容
    Module    string  // 模块分组：common/nav/button/footer/form/error
    IsActive  bool    // 启用状态
    SortOrder int     // 排序
}
```

### 6. 默认词条（已内置 36 个英文 + 23 个中文）

覆盖核心 UI 文案：导航（nav.*）、按钮（btn.*）、表单（form.*）、页脚（footer.*）、通用（common.*）、错误（error.*）

### 7. 内容类多语言（产品/页面/博客等）

数据库已有关联翻译表（ProductTranslation / PageTranslation / BlogTranslation 等），通过 `lang` 参数返回对应语言翻译，无该语言翻译时回退英文。

## 二、媒体源配置方案

### 1. 设计目标

图片/视频支持三种来源，后台配置存储源（公网 IP+PORT 或域名），媒体通过存储源地址 + 路径即可访问；视频支持 YouTube 等平台嵌入。

### 2. 媒体来源类型

| 来源 | 说明 |
|------|------|
| local | 本地磁盘文件（通过 IP+PORT 访问） |
| minio | MinIO/S3 对象存储（通过 IP+PORT+Bucket 访问） |
| external | 外部链接（YouTube、第三方 CDN、任意 URL） |

### 3. 存储源配置（storage_sources 表，后台可配置 IP+PORT）

```go
type StorageSource struct {
    Name     string    // 名称
    Code     string    // 唯一标识：local / minio / cdn
    Type     MediaSource // local / minio / external
    Protocol string    // http / https
    Host     string    // IP 或域名，如 192.168.1.100 或 cdn.example.com
    Port     string    // 端口，如 9000（可空）
    BasePath string    // 基础路径
    Bucket   string    // 对象存储桶名
    IsDefault bool     // 是否默认源
    IsActive  bool     // 是否启用
}
```

**URL 组装规则**：`{protocol}://{host}:{port}{basePath}/{bucket}/{path}`

示例：`http://192.168.1.100:9000/sportswear/products/2026-08/uuid.jpg`

### 4. 媒体扩展字段（media 表已扩展）

```go
type Media struct {
    ...
    Source     MediaSource   // local / minio / external
    Provider   VideoProvider // self / youtube / vimeo / bilibili
    ExternalID string        // 视频平台视频 ID
    EmbedURL   string        // 嵌入 URL（iframe 地址）
    Path       string        // 存储路径（local/minio）
}
```

### 5. 视频平台支持（YouTube/Vimeo/B站）

后台配置视频时：
- `provider = youtube` + `external_id = 视频ID` → 自动生成嵌入链接 `https://www.youtube.com/embed/{id}`
- `provider = vimeo` + `external_id` → `https://player.vimeo.com/video/{id}`
- `provider = self` + `url` → 自托管 mp4/webm 直接播放

```

  "nav.products": "产品",
  "btn.submit": "提交",

  ...

```
