# 运动服饰 OEM/ODM 数字化平台 — 系统需求文档

> 文档版本：v1.1  
> 更新日期：2026-08-22  
> 项目概述：国际化 B2B 运动服饰 OEM/ODM 数字化平台，包含门户网站、后台管理、后端 API 三个子系统，代码基于实际源码分析整理

---

## 一、系统概览

### 1.1 系统架构

```
┌─────────────────────────────────────────────────────────────────┐
│                       全球用户 (Global Users)                     │
│              CDN / Cloudflare 加速全球访问                         │
├─────────────────────────────────────────────────────────────────┤
│   sportswear-portal (Nuxt 3 SSR)                                 │
│   → 门户官网 portal.example.com                                   │
│   → 面向全球访客：产品展示、内容浏览、询盘提交                      │
│   → 多语言：英语/中文/西班牙语/法语                               │
├─────────────────────────────────────────────────────────────────┤
│   sportswear-admin (Vue 3 SPA)                                    │
│   → 管理后台 admin.example.com                                     │
│   → 面向运营人员：内容管理、产品管理、询盘管理、系统配置              │
│   → RBAC 权限体系，Element Plus 组件库                             │
├─────────────────────────────────────────────────────────────────┤
│   sportswear-platform (Go + Gin + GORM)                           │
│   → 后端 API api.example.com                                      │
│   → Public API + Admin API 双通道                                  │
│   → 版本化发布、多语言、软删除、审计日志、流量分析                    │
├─────────────────────────────────────────────────────────────────┤
│   PostgreSQL 15+  │  Redis 7+  │  MinIO / S3 对象存储             │
└─────────────────────────────────────────────────────────────────┘
```

### 1.3 三个子系统的关系

- **sportswear-platform** 是核心业务引擎，提供所有数据读写 API
- **sportswear-admin** 通过 Admin API 管理所有业务数据，JWT 认证，RBAC 权限控制
- **sportswear-portal** 通过 Public API 读取公开数据，展示给访客，无需认证
- 后台编辑的内容（产品/页面/博客等）通过草稿/发布机制控制前台可见性
- 门户支持主题配置，后台可实时调整门户视觉风格，无需重新部署
- 所有 ID 使用 UUID，支持分布式部署

## 二、sportswear-portal（门户网站）

### 2.1 概述

- 域名：`portal.example.com`
- 框架：Nuxt 3 + Vue 3 + TypeScript
- 渲染模式：SSR（服务端渲染，SEO 核心）
- 多语言策略：子路径前缀（`/en/`、`/zh/`、`/es/`、`/fr/`）
- 构建：`nuxt generate` 静态生成 / `nuxt build` 服务端渲染
- 运行时配置：`NUXT_PUBLIC_API_BASE` 指向后端 API 地址

### 2.2 页面路由结构

```
pages/
├── index.vue              # 首页 /
├── contact.vue            # 联系页 /contact
├── products/
│   ├── index.vue          # 产品列表 /products
│   └── _slug.vue          # 产品详情 /products/:slug
├── blog/
│   ├── index.vue          # 博客列表 /blog
│   └── _slug.vue          # 博客详情 /blog/:slug
├── cases/
│   └── index.vue          # 案例列表 /cases
└── faq/
    └── index.vue          # FAQ 页 /faq
```

### 2.3 页面详细说明

#### 2.3.1 首页（`/`）
- **Hero 区域**：渐变色背景（使用主题配置的 primary_color + secondary_color），标题、副标题、CTA 按钮（获取报价，链接到 /contact）
- **推荐产品**：展示 4 个精选产品卡片（占位图片、SKU、简介、类型标签），链接到产品详情页
- **产品分类**：展示所有分类标签
- **最新博客**：展示 3 篇最新博客摘要，链接到博客详情页
- **认证展示**：展示工厂认证标签
- 所有数据通过 `GET /public/home` 接口聚合获取

#### 2.3.2 产品列表页（`/products`）
- 产品卡片网格展示（4 列）
- 暂未实现分页和筛选 UI（后端 API 已支持分页和 keyword 筛选）
- 默认加载 20 条产品

#### 2.3.3 产品详情页（`/products/:slug`）
- 通过 API 获取产品详情
- 展示产品完整信息（图片、视频、规格、阐述、面料、定制能力、MOQ 等）

#### 2.3.4 博客列表页（`/blog`）
- 博客文章列表

#### 2.3.5 博客详情页（`/blog/:slug`）
- 博客完整内容展示

#### 2.3.6 案例列表页（`/cases`）
- 客户案例展示

#### 2.3.7 FAQ 页（`/faq`）
- 常见问题分类展示，支持按分类筛选

#### 2.3.8 联系页（`/contact`）
- 询盘表单字段：姓名（必填）、邮箱（必填）、电话、公司、留言（必填）
- 表单提交到 `POST /public/leads`，project_type 为 "contact"
- 提交后显示成功消息
- 联系方式展示：Email、Phone、Address、Working Hours

### 2.4 核心功能

#### 2.4.1 多语言（i18n）
- 支持语言：英语（en）、中文（zh）、西班牙语（es）、法语（fr）
- 子路径前缀策略：`/en/products`、`/zh/products`
- 浏览器语言自动检测（Cookie 记录：`i18n_redirected`）
- `redirectOn: 'root'` 只在根路径自动重定向
- 默认语言：英语（en）
- SEO hreflang 标签自动生成
- 前端 UI 翻译文件：`locales/en.json`、`locales/zh.json` 等
- 后端 API 数据根据 `lang` 参数返回对应语言翻译内容
- 页面导航栏含语言切换下拉菜单

#### 2.4.2 布局（Layout）
- **Header**：sticky 固定顶部，白色背景阴影
  - Logo（纯文本：Sportswear OEM/ODM）
  - 导航菜单（Home / Products / Cases / Blog / FAQ / Contact）
  - 语言切换下拉菜单
  - CTA 按钮（Get a Quote）
- **Footer**：深蓝色背景
  - 三列：About Us（公司简介）/ Quick Links（导航链接）/ Contact Info（联系方式）
  - 版权信息

#### 2.4.3 SEO
- 每个页面通过 `useHead` 设置自定义 Title、Description
- 自动生成 `sitemap.xml`（通过 Nitro prerender）
- 多语言 SEO 标签（hreflang）
- 全局 meta 标签（keywords、description）
- SSR 确保搜索引擎可抓取

#### 2.4.4 主题定制
- 后台可配置：primary_color、secondary_color、accent_color
- 按钮样式、圆角、间距、字体
- 导航栏样式（sticky/transparent/solid）、高度
- 卡片圆角、区块间距、容器宽度
- Footer 栏数
- 前端通过 `GET /public/theme` 接口动态读取主题配置并渲染

#### 2.4.5 导航管理
- 导航数据由后台通过 `GET /public/navigations?type=header` 接口动态获取
- 支持 header / footer 两种类型
- 无限级导航层级（ParentID 自引用）

#### 2.4.6 页面模块化
- 页面由模块组成（banner、product_recommend、oem、odm、factory、production、case、certification、blog、contact、text、image、video）
- 后台可配置页面模块的显隐、顺序、内容
- 支持版本管理（草稿与线上分离）

### 2.5 API 客户端（useApi composable）

所有 API 调用封装在 `composables/useApi.ts` 中，使用 `ofetch` 创建 HTTP 客户端：

```
baseURL = runtimeConfig.public.apiBase  // 默认 http://localhost:8080/api/v1
自动附加 lang 参数（当前语言）
统一错误处理（onResponseError）
```

#### 3.2.3 权限守卫机制
- 路由级守卫：`router.beforeEach` 检查 `to.meta.permission`
- 接口级守卫：`middleware.RequirePermission` 中间件
- 支持 `RequireAnyPermission`（多个权限满足其一即可）
- 支持应用维度权限隔离（AppID 作用域）

### 3.3 功能模块详细说明

#### 3.3.1 仪表盘（Dashboard）
- **统计卡片**：今日询盘数、本周询盘数、本月询盘数、高价值询盘数、成交询盘数
- **热门产品**：按询盘数量排行的产品 Top 列表
- **热门国家**：按询盘数量排行的国家 Top 列表

#### 3.3.2 产品管理（PIM）

**产品列表**：
- 表格展示：SKU、Slug、类型、状态、MOQ
- 搜索：按 SKU/名称搜索
- 筛选：按状态筛选（草稿/已发布/已下线）
- 操作：编辑、发布/下线、删除
- 分页
- 新建产品按钮

**产品创建/编辑表单字段**：
- 基本信息：SKU（必填）、Slug（必填）、类型（OEM/ODM/Both）、性别（中性/男装/女装/童装）、状态
- 分类归属
- 详细描述：简介、描述、特性、用途
- 规格参数：材质、成分、重量、弹性、版型、支撑等级、季节、尺码范围
- MOQ 配置：打样 MOQ（默认1）、大货 MOQ（默认300）、颜色 MOQ（默认100）、尺码 MOQ（默认100）
- 图片管理：主图、图库、模特图、细节图、面料图、工艺图、尺码图、包装图
- 视频管理：产品视频、生产视频、工艺视频、使用视频
- 定制能力：Logo、颜色、面料、图案、印花、刺绣、标牌、吊牌、包装、尺码、版型、拉链、纽扣、腰带、配件
- 系列关联、面料关联
- SEO 配置
- 多语言翻译管理

**产品分类管理**：
- 无限级分类树（ParentID 自引用）
- 分类名称、Slug、排序、启用状态、图片
- 支持多级子分类

**产品系列管理**：
- 系列名称、Slug、排序、状态
- 发布/下架
- 多对多关联产品

**面料数据库管理**：
- 名称、编码、成分、重量、弹性
- 透气性、吸湿排汗、柔软度、压缩性、UV 防护、环保属性
- 描述
- 发布/下架

#### 3.3.3 CMS 内容管理

**页面管理**：
- 页面列表：标题、Slug、类型（home/normal/product/oem/odm/private_label/factory/production/blog/case/faq/contact/seo_landing）、状态（draft/review/published/offline/archived）
- 页面编辑器：模块化搭建
- 模块类型：banner、product_recommend、oem、odm、factory、production、case、certification、blog、contact、text、image、video
- 每个模块配置：标题、排序、可见性、JSONB 配置
- 版本管理：页面版本表（版本号、状态、JSONB 快照、发布人、版本备注）
- 工作流：编辑 → 保存草稿版本 → 预览确认 → 发布版本 → 前台立即生效
- 支持版本回滚

**博客管理**：
- 分类：oem_guide、odm_guide、fabric、trend、sourcing、brand、production、industry
- 字段：标题、Slug、分类、标签、作者、封面图、内容、状态
- 多语言翻译
- 发布/下架

**案例管理**：
- 字段：标题、Slug、客户行业、项目类型（OEM/ODM/Private Label）
- 客户需求、问题、解决方案、流程、成果
- 封面图、状态
- 多语言翻译

**FAQ 管理**：
- 分类：moq、oem、odm、sample、payment、production、logistics、fabric、quality、certification
- 字段：问题、答案、分类、语言、排序
- 多语言翻译

**工厂管理**：
- 字段：名称、位置、面积、员工数、生产线数
- 设备、月产能、年产能、仓库
- 质量管理、生产能力描述
- 图片
- 发布/下架

**认证管理**：
- 字段：名称、编号、颁发日期、到期日期
- 图片、PDF 文件
- 发布/下架

**生产流程管理**：
- 字段：名称、描述、图片、视频、排序
- 发布/下架

#### 3.3.4 询盘管理（CRM）

**询盘列表**：
- 表格展示：姓名、公司、邮箱、国家、状态、评分
- 搜索：按姓名/邮箱/公司搜索
- 筛选：按状态筛选
- 分页

**询盘详情**：
- 完整信息展示：姓名、公司、邮箱、电话、国家、项目类型、产品分类、数量、来源、评分、留言
- 跟进记录列表

**询盘状态流转**：
```
new → contacted → confirmed → quoted → sampling → negotiating → won
                                                              → lost
                                                              → spam
```

**询盘跟进**：
- 跟进方式：email、whatsapp、phone、meeting、other
- 跟进内容
- 下次跟进时间

**询盘评分系统**：
- 自动评分（0-100）
- 评分等级：high（>=80）、medium（>=50）、normal、low
- 高价值询盘标记

**报价管理**：
- 报价单号（自动生成）、数量、单价、总价、币种
- MOQ、交期（Lead Time）、付款条款、运输方式
- 有效期
- 报价状态：draft、sent、viewed、accepted、rejected、expired

#### 3.3.5 媒体资源管理

**媒体列表**：
- 展示：原始文件名、文件类型、大小、URL、分类、来源、创建时间
- 类型：image / video / file
- 分类：home、product、oem、odm、factory、production、case、blog、certification、public
- 来源：local（本地磁盘）/ minio（MinIO/S3）/ external（外部链接）
- 视频平台：self（自托管）、youtube、vimeo、bilibili
- 支持 WebP 和 AVIF 格式转换
- 图片尺寸记录（宽x高）

**功能**：
- 上传文件（支持图片/视频/文件）

### 4.6 核心业务逻辑

#### 4.6.1 内容发布机制
- 后台编辑内容 → 保存为草稿状态（不影响前台）
- 手动发布 → 状态变为 "published" → 前台可见
- 手动下架 → 状态变为 "offline" → 前台不可见
- 页面支持版本管理：编辑保存为新版本（draft），发布后线上生效
- 版本快照：完整页面信息 + 全部模块配置（JSONB）

#### 4.6.2 多语言翻译机制
- 每个可翻译实体有独立的翻译表（如 `product_translations`）
- 翻译状态：untranslated / draft / translated / pending / published
- 查询时根据 `lang` 参数返回对应语言内容
- 支持语言回退（当前语言无翻译时返回默认语言 en）
- 本地化服务：`LocalizeProduct`、`LocalizeProducts`、`LocalizePage`、`LocalizeBlog`、`LocalizeBlogs`、`LocalizeCase`、`LocalizeCases`

#### 4.6.3 媒体资源管理
- 支持多种存储源：local（本地磁盘）、minio（MinIO/S3）、external（外部链接）
- 配置化存储源切换，一个存储源为默认
- 支持视频平台：self（自托管）、youtube、vimeo、bilibili
- 支持 WebP 和 AVIF 格式转换
- 图片尺寸记录
- 统一资源管理，跨实体引用
- `ResolveAccessURL` 方法根据存储源解析最终访问 URL

#### 4.6.4 软删除机制
- 所有业务实体继承 `BaseModel`，包含 `DeletedAt` 字段
- 删除 = 软删除（标记 deleted_at 时间戳）
- 后台回收站可查看和恢复已删除数据
- 可彻底删除清除数据（purge）

#### 4.6.5 询盘评分机制
- 自动评分系统（0-100 分）
- 评分等级：high（>=80）、medium（>=50）、normal、low
- 高价值询盘可标记和优先处理

#### 4.6.6 缓存策略
- Redis 缓存页面数据
- 缓存失效策略配合内容发布

#### 4.6.7 地理定位
- 通过 IP 地址解析访客地理位置
- 返回对应国家、建议语言、货币、时区
- 支持前端自动适配

#### 4.6.8 时区处理
- 从 `X-Timezone` 请求头或 `tz` 参数解析访客时区
- 服务器返回 UTC 时间和本地时间
- 预置常用时区列表

## 五、数据流与交互

### 5.1 内容管理流程

```
后台管理员登录
  → 进入产品/页面/博客等管理模块
  → 编辑内容并保存（状态=draft，不影响前台）
  → 预览确认
  → 点击发布（状态=published）
  → 缓存失效
  → 前台访问时通过 Public API 获取最新发布内容
```

### 5.2 询盘处理流程

```
门户访客填写询盘表单
  → POST /api/v1/public/leads（受频率限制保护）
  → 系统创建 Lead（状态=new，自动评分）
  → 后台通知管理员（notification type=new_lead）
  → 销售查看询盘详情
  → 添加跟进记录（电话/邮件/WhatsApp等）
  → 更新询盘状态（contacted → qualified → quoted → ...）
  → 创建报价（发送给客户）
  → 跟进直至成交或流失
```

### 5.3 多语言内容展示流程

```
访客访问 /zh/products
  → 前端检测语言为 zh
  → 请求 API 时带 lang=zh 参数
  → 后端查询该语言翻译内容
  → 有翻译 → 返回翻译内容
  → 无翻译 → 回退到默认语言（en）
  → 前端渲染展示
```

### 5.4 主题配置流程

```
后台管理员修改主题配置（颜色、字体、布局等）
  → PUT /api/v1/admin/theme/:key
  → 保存到 theme_configs 表
  → 门户 GET /api/v1/public/theme 读取配置
  → 前端动态应用主题样式
  → 实时生效，无需重新部署
```

### 5.5 页面版本发布流程

```
后台编辑页面
  → POST /api/v1/admin/pages/:id/versions 保存草稿版本
  → 系统创建新版本（status=draft），保存完整快照
  → 预览确认
  → POST /api/v1/admin/versions/:id/publish 发布版本
  → 版本状态变更为 published
  → 页面最新发布版本生效
  → 支持回滚到历史版本
```

### 11.2 API 响应格式

**成功响应**：
```json
{
  "success": true,
  "data": { ... },
  "requestId": "uuid-string"
}
```

**分页响应**：
```json
{
  "success": true,
  "data": {
    "items": [ ... ],
    "page": 1,
    "pageSize": 20,
    "total": 100,
    "totalPages": 5
  },
  "requestId": "uuid-string"
}
```

**错误响应**：
```json
{
  "success": false,
  "code": "NOT_FOUND",
  "message": "资源不存在",
  "requestId": "uuid-string"
}
```
